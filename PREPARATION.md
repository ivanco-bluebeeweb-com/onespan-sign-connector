- **Название:** OneSpan Sign Connector

- **Официальный сайт:** https://onespan.com
- **Модель доступа:** API Key (Authorization: Basic <key>)

## 2. Человеческая проблема
Когда офицер безопасности банка сталкивается с задачей высокозащищенный enterprise-электронный документооборот с требованиями строгой банковской идентификации, ей приходится вручную переключаться между сервисами, что приводит к задержкам и потере контроля данных.

## 3. Пользователи и роли
- **офицер безопасности банка:** операционная работа, контроль выполнения сценариев.
- **Администратор безопасности / ИТ:** управление правами, ротация ключей доступа.
- **Оператор Imperal Cloud:** автоматизация сценариев через безопасные протоколы ICNLI.

## 4. Первичный сценарий
`создание защищенного пакета -> валидация личности подписанта -> фиксация электронной подписи`.

## 5. Границы и безопасность
- Никаких синтетических шаблонов от других предметных областей.
- Использование только принципа Bring Your Own Credentials (BYOC).
- Маскирование секретов и аудит всех изменений.
